# Text logo

The name "SiivOS" with the two glints off the top-left corner of the S. Use it wherever a plain
logo fits: the app's sidebar (drawn in code by `SiivOSLogo`), the README, a website.

- `SiivOS-logo-for-dark-backgrounds`: soft white `#F1F7F3` with mint `#5EE6A8` for "OS".
- `SiivOS-logo-for-light-backgrounds`: deep green `#0B3D30` with jade `#178A64` for "OS".

The big glint takes the colour of "Siiv", the small one the colour of "OS". Each comes as SVG
(any size) and PNG (1200 px wide). The name is drawn from Nunito ExtraBold outlines (SIL Open
Font License).
