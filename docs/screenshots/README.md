# Screenshots

Pictures of SiivOS for the main README. They are taken on a real Mac, so look at each one
before adding it: nothing in it should be something you would not show a stranger, such as
file names, folder names or the names of apps you would rather keep to yourself.

Wanted, in dark mode, with the window at its normal size:

| File | What it shows |
|------|---------------|
| `welcome.png` | The first step of the welcome, after the logo has finished drawing |
| `overview.png` | The Overview after Check This Mac has run |
| `cleanup.png` | Cleanup, Clutter, with results and their Safe to remove and Check first labels |
| `disk-map.png` | Cleanup, Disk Map, showing the home folder |
| `health-timeline.png` | The Health Timeline with its score and charts |

To take one: press Command-Shift-4, then Space, then click the SiivOS window. The picture
is saved on the Desktop.
